# タスク管理アプリ 要件定義書

## 1. 概要
Trello風のシンプルなタスク管理アプリ。ボード・リスト・カードの3階層でタスクを管理する。
まずは最小機能（MVP）で動くものを作り、後から機能を拡張していく。

## 2. スコープ（MVP）

### 対象
- ブラウザのみで完結するSPA（サーバー不要）
- データはブラウザの localStorage に保存し、タブ/ブラウザを閉じても保持される
- 1ユーザー・1ボードを前提とする（複数ボード・複数ユーザーは対象外）

### 対象外（今回はやらない）
- ユーザー認証・ログイン
- サーバー・データベースとの連携
- 複数ボードの管理
- 複数人での同時編集・共有

## 3. 機能要件

| ID | 機能 | 内容 |
|----|------|------|
| F1 | リスト作成 | ボードに新しいリスト（列）を追加できる |
| F2 | リスト削除 | 不要なリストを削除できる |
| F3 | リスト名編集 | リストのタイトルを変更できる |
| F4 | カード作成 | リストに新しいカード（タスク）を追加できる |
| F5 | カード削除 | カードを削除できる |
| F6 | カード編集 | カードのタイトルを編集できる |
| F7 | カード移動（DnD） | カードをドラッグ&ドロップで別のリスト・別の位置に移動できる |
| F8 | データ永続化 | 上記の操作結果は localStorage に保存され、再読み込み・再訪問後も保持される |

## 4. 非機能要件

- 対応環境: 最新のデスクトップブラウザ（Chrome / Edge）
- レスポンシブ対応は必須としない（PC画面優先）
- 特別なパフォーマンス要件はなし（個人利用規模のデータ量を想定）

## 5. データモデル（案）

```
Board
 └─ Lists[]
     - id
     - title
     - order（表示順）
     - Cards[]
         - id
         - title
         - order（リスト内の表示順）
```

localStorage には Board 全体を1つのJSONとして保存する。

## 6. 画面イメージ

```
+--------------------------------------------------+
| [リスト: 未着手]   [リスト: 進行中]   [リスト: 完了] |
| ---------------   ---------------   ------------ |
| □ カードA          □ カードC          □ カードE    |
| □ カードB          □ カードD                       |
| [+ カード追加]      [+ カード追加]      [+ カード追加]|
+--------------------------------------------------+
| [+ リスト追加]                                     |
+--------------------------------------------------+
```

## 7. 技術スタック（案）

- React（+ Vite）
- ドラッグ&ドロップ: dnd-kit などのライブラリ
- 保存先: ブラウザ localStorage
- ビルド/実行環境: Node.js

## 8. 今後の拡張候補（MVP後）

- 複数ボード管理
- カードの詳細（説明・期限・ラベル・チェックリスト）
- サーバー保存・複数端末同期
- ユーザー認証・複数人共有
