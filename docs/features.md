# TaskBoard 機能一覧

[要件定義書](requirements.md) に戻る

| ID | 機能 | 内容 |
|----|------|------|
| F1 | タスク作成 | 「未着手」カラムの「＋タスク追加」から作成モーダルを開き、タスクを登録できる。新規タスクは「未着手」カラムの末尾に追加する |
| F2 | タスク編集 | タスクカードをクリックして編集モーダルを開き、タイトル・説明・優先度・期限を変更できる |
| F3 | タスク削除 | 編集モーダルの「削除」から削除確認ダイアログを開き、確定するとタスクを削除する |
| F4 | タスク移動・並び替え（DnD） | タスクカードをドラッグ&ドロップで、同一カラム内の任意の位置、または別カラムの任意の位置に移動できる。並び順は保存される |
| F5 | 優先度順・期限順ソート | 各カラム上部のボタン（「優先度順」「期限順」）を押すと、そのカラム内のタスクを一度だけ並べ替える（1回限りの操作で、ソート状態は固定されない） |
| F6 | データ永続化 | 上記の操作結果はバックエンドAPI経由でDB（SQLite）に保存され、再読み込み・再訪問後も保持される |

## タスクの項目

| 項目 | 入力 | 内容 |
|------|------|------|
| タイトル | 必須・1行テキスト | 100文字以内 |
| 説明 | 任意・複数行テキスト | タスクの詳細メモ |
| 優先度 | ラジオボタン（高・中・低） | 初期値は「中」。必ずいずれかが選択された状態とする |
| 期限 | 任意・日付ピッカー | 未入力の場合は「期限なし」 |

## カラム

カラムは「未着手」「作業中」「完了」の3つで固定とする（追加・削除・名称変更はMVPの対象外）。

## 並び替えの方針

- ソートボタンは「現在の並びを優先度順／期限順に並べ直す」1回限りの操作とする。実行結果は通常の並び順（position）として保存する
- ソート実行後も、タスクは自由にDnDで並び替えできる（ソートが解除・固定されることはない）
- ソート後に新規追加したタスクはカラム末尾に追加する（自動でソート位置に挿入しない）
- 優先度順は「高 → 中 → 低」、期限順は「期限が近い順 → 期限なし」とする。同順位のタスクは現在の並び順を維持する（安定ソート）
