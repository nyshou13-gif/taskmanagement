# TaskBoard 画面設計

[要件定義書](requirements.md) に戻る

実際の画面イメージは [mockup/index.html](../mockup/index.html) を参照（ブラウザで開いて確認できる）。

## 1. ボード画面

```
+------------------------------------------------------------+
| TaskBoard                                                  |
+------------------------------------------------------------+
| 未着手 (3)            作業中 (2)          完了 (1)         |
| 並び替え[優先度順][期限順] 並び替え[優先度順][期限順] 並び替え[優先度順][期限順] |
| +----------------+   +----------------+  +--------------+  |
| | タスクA         |   | タスクD         |  | タスクF       |  |
| | 優先度:高 期限:..|   | 優先度:中 期限:..|  | 優先度:低 ..  |  |
| +----------------+   +----------------+  +--------------+  |
| +----------------+   +----------------+                     |
| | タスクB         |   | タスクE         |                     |
| +----------------+   +----------------+                     |
| [＋タスク追加]                                              |
+------------------------------------------------------------+
```

- ヘッダーにアプリ名「TaskBoard」を表示する
- 「未着手」「作業中」「完了」の3カラムを横並びで表示する（カラムは固定で、追加・削除・名称変更はできない）
- 「＋タスク追加」ボタンは「未着手」カラムにのみ配置する
- 各タスクカードには、タイトル・優先度・期限を表示する（期限が未設定の場合は「期限: なし」）
- タスクカードはドラッグ&ドロップで、同一カラム内の並び替え・別カラムへの移動ができる
- 各カラム上部に並び替えボタン（優先度順／期限順）を配置する
- 画面はボード画面の1つのみ（画面遷移は発生せず、モーダル・ダイアログで完結する）

## 2. タスク作成／編集モーダル

作成と編集で同じモーダルを使い、タイトル表示（「タスクを作成」／「タスクを編集」）とボタン構成のみ異なる。

| 要素 | 内容 |
|------|------|
| タイトル入力欄 | 1行テキスト。**必須**（「必須」ラベルを表示） |
| 説明入力欄 | 複数行テキスト（任意） |
| 優先度 | 「高」「中」「低」のラジオボタン。作成時の初期値は「中」 |
| 期限 | 日付ピッカー（任意） |
| 「保存」ボタン | 入力内容を確定してモーダルを閉じる |
| 「キャンセル」ボタン | 入力内容を破棄してモーダルを閉じる |
| 「削除」ボタン | **編集モーダルの場合のみ**表示。押すと削除確認ダイアログを開く |

- モーダル外のクリックまたはEscキーはキャンセル扱いとする
- 新規作成の場合、保存したタスクは「未着手」カラムの末尾に追加される

## 3. 削除確認ダイアログ

| 要素 | 内容 |
|------|------|
| 見出し | 「タスクを削除しますか？」 |
| 削除対象 | 削除するタスクのタイトルを「」付きで表示する |
| 注意文 | 「この操作は取り消せません。」を表示する |
| 「削除」ボタン | タスクを削除してダイアログを閉じる |
| 「キャンセル」ボタン | 削除せずにダイアログを閉じる（Escキー・ダイアログ外クリックも同様） |

## 4. 操作の振る舞い

| 操作 | UI要素 | ルール |
|------|--------|--------|
| タスク作成 | 「未着手」カラムの「＋タスク追加」 | 作成モーダルを開く |
| タスク編集 | タスクカードをクリック | 編集モーダルを開く |
| タスク削除 | 編集モーダルの「削除」 | 削除確認ダイアログを経て削除する |
| タスク移動・並び替え（DnD） | タスクカードをドラッグして任意のカラム・位置にドロップ | ドロップ先が不正な場合（対象外領域など）は元の位置に戻す。ドラッグ中のドロップ先カラムは破線で強調する |
| 優先度順・期限順ソート | 各カラム上部の「優先度順」「期限順」ボタン | 押した時点で1回だけ並び替える。以降もDnDで自由に並び替え可能（ソート状態は保持しない） |

## 5. バリデーション・エラー表示

| ケース | 表示位置・内容 |
|--------|----------------|
| タイトルが未入力のまま保存しようとした場合 | タイトル入力欄の直下に赤字で「タイトルを入力してください」と表示し、保存不可とする |
| タイトルが100文字を超えた場合 | タイトル入力欄の直下に赤字で「100文字以内で入力してください」と表示し、保存不可とする |
| バックエンドAPIとの通信に失敗した場合（サーバー未起動・タイムアウト等） | 画面上部にエラーバナーを表示し「サーバーとの通信に失敗しました。しばらくしてから再度お試しください」と案内する。直前の操作は反映せずロールバックする |
| APIから予期しないエラーレスポンス（5xx等）が返却された場合 | 画面上部にエラーバナーを表示し「データの保存に失敗しました」と案内し、操作前の状態を維持する |

（エラーバナーはモックには含まれていない。実装時に追加する）
